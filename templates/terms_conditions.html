ShopEase Academic Project

Project Notice: ShopEase is an academic project developed to demonstrate an e-commerce application and cloud infrastructure on AWS. It is not a real commercial shopping platform.
1. Academic Project

ShopEase is developed for educational, demonstration and case-study purposes. The website demonstrates the functionality and infrastructure of a cloud-based e-commerce application.

2. Customer Accounts

Customers may create accounts and use features such as profile management, saved addresses, cart, wishlist, checkout and order history for demonstration purposes.

3. Products and Prices

Products, images, descriptions, variants, quantities and prices displayed on ShopEase are demonstration catalog data and do not represent an actual commercial inventory.

4. Cart and Wishlist

Customers can add products to their cart or wishlist to demonstrate typical e-commerce functionality. Adding a product to a wishlist does not represent a real product reservation.

5. Orders

Customers can complete the checkout process and create demonstration orders. Order information is stored so that the order workflow and order history can be demonstrated.

6. Payment

Payment functionality, where applicable, is intended for demonstration purposes only. Customers should not treat the application as a real commercial payment service.

7. Simulated Delivery Status

ShopEase uses simulated order progression for project demonstration.

After an order is placed, its status progresses automatically through stages such as:

  • Pending
  • Confirmed
  • Out for Delivery
  • Delivered

These statuses are simulated and are not connected to an actual courier, delivery company or logistics system.

8. Demonstration Data

Customer information, product information, addresses, orders and other records may contain test or demonstration data created for the project.

9. AWS Infrastructure Case Study

The ShopEase application is used as the application component of an AWS cloud infrastructure case study. The project demonstrates services and concepts such as networking, IAM, S3, EC2, load balancing, Auto Scaling, RDS, EFS, EBS and CloudWatch.

10. No Commercial Transaction

ShopEase does not represent a real online retailer. No product purchase, delivery commitment or commercial transaction should be considered valid outside the scope of the academic demonstration.

11. Changes to the Project

Features and functionality may be modified as part of the development and evaluation of the ShopEase academic project.
