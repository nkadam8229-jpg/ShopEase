Privacy Notice

ShopEase Academic Project

Project Notice: ShopEase is an academic e-commerce and cloud-infrastructure project created for educational and demonstration purposes. It is not a real commercial e-commerce service.
1. Information Used in the Project

ShopEase uses sample customer information such as name, email address, phone number and delivery address to demonstrate normal e-commerce functionality.

2. Purpose of the Information

The information is used only to demonstrate features such as customer accounts, saved addresses, shopping carts, wishlists, checkout and order management.

3. Saved Addresses

Customers can save delivery addresses in their profile and select them during checkout. Additional recipient details can also be entered when placing an order for someone else.

4. Account Information

Customer account information is used to provide login, profile, cart, wishlist and order-history functionality within the project.

5. Orders and Delivery Status

Order information is stored to demonstrate the e-commerce order workflow and to display order details and status to the customer.

Delivery status in this project is simulated for demonstration purposes and is not connected to a real delivery or logistics service.

6. AWS Infrastructure Demonstration

ShopEase is also used to demonstrate cloud infrastructure concepts including AWS networking, compute, storage, database, monitoring and related services as described in the project case study.

7. No Commercial Data Processing

ShopEase is not being operated as a commercial retail service. The application is intended for academic evaluation, testing and demonstration.

8. Project Nature

Product information, customer accounts, orders, prices and other application data may be demonstration or test data created specifically for this project.

9. Updates

This notice may be updated if the functionality or scope of the ShopEase academic project changes.
